# Workshop Markdown Files

This folder contains the project requirements used during the **Vibe Coding Live** workshop.

## Available file

- [Sales Call Note Builder Prototype requirements](./sales_call_note_builder_prototype_requirements.md) — the build specification for the Salesforce Lightning Web Component prototype, including its field, interface, data-storage, error-handling, and testing requirements.

## How to use this file

1. Open the requirements file using the link above.
2. Download it or make it available to your AI coding environment.
3. Give the file to the coding agent before submitting [Prompt 1](../prompts/prompt_1.txt).
4. Keep it available while reviewing the agent's plan and generated work.

The requirements file is the source of truth for the initial prototype.

> [!NOTE]
> A later workshop prompt intentionally changes the initial requirement that questions be hard-coded. Follow the prompts in order so each stage builds on the previous one.

## GitHub tips

- To save the file, open it and select the **Download raw file** button.
- To copy its contents, open it and select the **Copy raw file** button.
- You do not need to clone the repository or use Git from the command line to participate in the workshop.
